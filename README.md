# Página Ciberweb

Página de presentación para mostrar cómo el diseño web puede transmitir la identidad de cada negocio mediante imágenes, video, mensajes y experiencias.

**[Abrir la vista previa en GitHub Pages](https://jhonretana2002-del.github.io/pagina-ciberweb/)**

## Documento por fases y checklist

El trabajo se organiza en tres fases con tareas verificables, criterios de cierre y pendientes:

**[Consultar el plan de adaptación de Ciberweb](docs/PLAN_CIBERWEB.md)**

## Sectores

Clínicas, centros educativos, joyerías, veterinarias, ropa, calzado y deportes.

La propuesta toma como referencia el formato visual de [WAM Digital](https://wamdigital.com/) y utiliza mensajes e identidad propios para Ciberweb. Las escenas representan conceptos de diseño para cada sector.

## Contenido y publicación

- index.html: estructura, mensajes, conceptos y ventanas de exploración.
- styles.css: composición, estilos y adaptación a móvil.
- script.js: navegación, conceptos y controles de video.
- assets/ciberweb: recursos audiovisuales optimizados.
- [Recursos visuales y créditos](docs/RECURSOS_VISUALES.md).
- [Validación](docs/VALIDACION.md).

GitHub Pages publica desde la raíz de la rama main. Los cambios subidos a esa rama actualizan la vista previa.

Los botones de WhatsApp y correo están preparados y muestran un aviso temporal. Sus enlaces se añadirán cuando el cliente los facilite.
